# PP-OCRv5 C++ Reference

These files are the original PP-OCRv5 C++ implementation used as the
pre/post-processing reference for `winui_mcp/ocr.py`.

They are kept for provenance and algorithm comparison only. They are not
built, imported, or packaged with `winui-mcp-server`; the runtime package uses
ONNX Runtime and OpenCV instead.

The C++ preprocessing and post-processing contract is shared with PP-OCRv6.
